## 1. 개념

### WebGL / 3D는 왜 CSR인가?

3D는 **GPU·WebGL·canvas**가 필요합니다. Node.js 서버에는 GPU 컨텍스트가 없어 **SSR로 3D 씬을 그릴 수 없습니다.**

```txt
SSR/SSG → HTML 문자열 (텍스트·레이아웃)
WebGL   → 브라우저 canvas (CSR only)
```

**Lab 메시지:** “렌더링 전략 논의의 연장선 — SEO 필요 없는 영역은 Client.”

### R3F란?

**React Three Fiber** — Three.js를 React 컴포넌트 트리로 씁니다.

```tsx
<Canvas>
  <mesh>
    <torusGeometry />
    <meshStandardMaterial />
  </mesh>
</Canvas>
```

**drei** — R3F용 헬퍼 (`OrbitControls`, `Environment` 등).

## 2. Live Lab — 무엇을 보여줄까?

LAB_PLAN: **Performance Ring** — fps 40 → 60 스토리

### 최소 씬 구성

1. **토러스(링)** 또는 원형 메시 — “성능 링” 메타포
2. **색/회전 속도** — after(60fps)일 때 더 부드러운 애니메이션 (선택)
3. **라벨** — `40 → 60 FPS` (HTML overlay 또는 drei `Html`)

### Fallback (필수)

| 조건 | 대체 UI |
|------|---------|
| `prefers-reduced-motion: reduce` | 2D — Recharts Line 또는 정적 이미지 |
| WebGL 초기화 실패 | 동일 2D fallback |

**지식:** 접근성 + 저사양 기기 — “3D는 있지만 everyone-first.”

**예시:**

```txt

fps 개선 스토리를 Performance Ring으로 시각화해

```

### Step 3 — 컴포넌트 구조

```txt

src/app/lab/3d/page.tsx                       # dynamic(ssr: false)
```

### Step 4 — dynamic import (charts와 동일 패턴)

```tsx
const Scene3D = dynamic(() => import("../_components/Scene3D"), {
  ssr: false,
  loading: () => <p>3D 씬 로딩 중…</p>,
});
```

### Step 5 — Fallback 로직 스케치

```tsx
"use client";
import { useEffect, useState } from "react";

function usePrefersReducedMotion() {
  const [reduced, setReduced] = useState(false);
  useEffect(() => {
    const mq = window.matchMedia("(prefers-reduced-motion: reduce)");
    setReduced(mq.matches);
    // listener...
  }, []);
  return reduced;
}

// reduced || webglError → <Scene3DFallback />
// else → <Canvas>...</Canvas>
```

**WebGL 실패 감지:** `Canvas` `onCreated` / error boundary 또는 canvas ref try/catch.

### Step 6 — Performance Ring (간단 버전)

```tsx
import { Canvas } from "@react-three/fiber";
import { OrbitControls } from "@react-three/drei";

function Ring() {
  return (
    <mesh rotation={[Math.PI / 2, 0, 0]}>
      <torusGeometry args={[1, 0.15, 16, 64]} />
      <meshStandardMaterial color="#3b82f6" />
    </mesh>
  );
}
```

`useFrame`으로 `rotation.z += delta * speed` — speed를 40/60 비율로 설명.

### Step 7 — How bullet

```txt
- Scene3D.tsx — @react-three/fiber Canvas, ssr: false
- PerformanceRing — torus + useFrame 애니메이션
- Scene3DFallback — prefers-reduced-motion / WebGL fail
- portfolioMetrics.fps — 40 → 60 카피 연결
```

### Step 8 — Trade-offs

```txt
장점: 임팩트·WebGL·React 통합 스토리
단점: 번들(three ~500KB+), GPU·배터리 — 씬 1개로 제한
```

### Step 9 — Verify

1. `/lab/3d` — WebGL 씬 표시, OrbitControls 드래그
2. **View Page Source** — canvas WebGL 내용 없음
3. Chrome DevTools → Rendering → **Emulate prefers-reduced-motion** → 2D fallback
4. (선택) WebGL 비활성 환경 시뮬레이션 → fallback
5. Lighthouse Performance — 번들 크기 메모 (면접용)
